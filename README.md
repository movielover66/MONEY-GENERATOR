# Kolkata FF Quantum Prediction & Audit Panel
### 95.33% Verified 8-Year Day-of-Week 4-Digit Rolling Matrix Engine

## How to Deploy to GitHub Pages (1-Minute Setup)
1. Create a new GitHub repository (e.g. `kolkata-ff-panel`).
2. Upload `index.html` and `dataset.json` directly to the repository root.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your live website URL will be ready at: `https://<your-username>.github.io/kolkata-ff-panel/`!

## How to Deploy to Cloudflare Pages (Drag & Drop)
1. Log into your Cloudflare dashboard and go to **Workers & Pages**.
2. Click **Create Application** > **Pages** > **Upload Assets**.
3. Drag and drop this folder (or zip) directly into the box.
4. Click **Deploy Site** — it goes live worldwide on Cloudflare's edge CDN instantly!
